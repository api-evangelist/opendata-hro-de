# OpenData.HRO - Portal für offene Data der Hansestadt Rostock (opendata-hro-de)

OpenData.HRO - Portal für offene Data der Hansestadt Rostock is a open data portal open-data portal for Germany running **CKAN**, exposing a standardized catalog API over ~281 datasets.
